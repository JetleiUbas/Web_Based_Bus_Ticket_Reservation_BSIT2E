WEB BASED BUS TICKET RESERVATION

Description

The Web-Based Bus Ticket Reservation System is a Java-based application for managing bus schedules, passenger reservations, and available seats.

Requirements

* Java JDK installed
* Java IDE (IntelliJ IDEA, Eclipse, NetBeans, etc.)

How to Run

1. Open the project in your Java IDE.
2. Locate Main.java.
3. Run Main.java.
4. Follow the instructions displayed in the console.
5. Choose an option from the main menu.
6. Enter the required passenger and reservation information.

Main Features

* Passenger Registration
* Bus Schedule Management
* Seat Availability
* Seat Selection
* Ticket Reservation
* Passenger Information
* Reservation History
* Booking Management
